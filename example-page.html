This is a sample page created from Markdown! You can use this as a template for your own pages.

How to Use This Template

  1. Copy this file and rename it to your page title (e.g., my-awesome-post.md)
  2. Update the header section (between the --- lines) with your page details
  3. Write your content in Markdown below the header
  4. Run npm run build to convert it to HTML
  5. Push to GitHub and your page is live!

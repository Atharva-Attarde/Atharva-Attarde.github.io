# LectureLens Demo Files Directory

Place your 3 files inside this folder:
`c:\Users\Atharva\Desktop\Atharva-Attarde.github.io\assets\lecturelens\`

---

### 1. The Page Visual (Image & PDF)
- **Image file (PNG or JPG):**
  Name it either `attention-page.png` (recommended) or `sample-page.png`.
  *(This is the high-res screenshot or export of the Attention page displayed on the website).*
- **PDF file (optional):**
  Name it `attention-page.pdf` if you want visitors to be able to click the *"Open PDF"* link.

### 2. The Audio File (MP3)
- **Audio file (MP3):**
  Name it either `attention-audio.mp3` (recommended) or `sample-audio.mp3`.
  *(The audio player will automatically detect and play this file).*

### 3. The Professor Transcript (Text)
- **Transcript file (TXT):**
  Name it `attention-transcript.txt` (or paste the text into this file).
  *(The web page automatically reads and formats this text into the professor transcript box).*

---

Both your **Homepage (`/`)** and your dedicated **LectureLens Page (`/lecturelens/`)** automatically load from this folder!
